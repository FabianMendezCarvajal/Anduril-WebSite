# Code blocks

Each file is a self-contained HTML + CSS component. In Squarespace: **Add block → Code**, set *Type* to
**HTML**, untick *Display source*, paste the whole file. No plan upgrade needed; none of them use JavaScript.

| File | Where | Section theme |
|---|---|---|
| `org-health-card.html` | Home hero, right column | Lightest 1 |
| `symptoms-strip.html` | Home, section 2 | Lightest 1 |
| `services-grid.html` | Home section 3, Services page | Lightest 1 |
| `process-steps.html` | Home section 4, How we work page | **Darkest 1** |
| `clouds-list.html` | Home section 5, Clouds page | Lightest 1 |
| `results-tiles.html` | Home section 6 | Lightest 1 |

Edit the text directly inside the block. Class names are prefixed `and-` so they never collide with Squarespace's own styles.
