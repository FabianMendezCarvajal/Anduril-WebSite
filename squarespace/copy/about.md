## Principles

*H2:* How we decide what to build

*Code Block:* `code-blocks/principles.html` (the same four as on the home page):

**We say no to work you don't need.**
If something you already own does the job, we configure it. Custom software is for what nothing off the shelf can do.

**We leave your team stronger.**
Every build ships with documentation and a walkthrough. The goal is systems your team can run without us.

**We measure adoption, not delivery.**
A feature nobody uses is a failed feature. We track logins, data entry and report views after launch.

**Certified, and still hands-on.**
Certified CRM consultants, data engineers and developers who still build every week.
